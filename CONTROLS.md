# Controls

**Azeroth Survivors** — classic WoW keys: A and D turn, W and S run, and the camera follows where you
face.

| When | Key / Input | Action |
|---|---|---|
| Menu | Click a race, gender, class and zone | make your pick (**Randomize** rolls one) |
| Menu | **Enter** (or **Enter World**) | start the run; the world travels to the zone picked |
| Playing | **W / S** or **↑ / ↓** | run forward / back |
| Playing | **A / D** or **← / →** | turn left / right (the camera turns with you) |
| Playing | **Q / E** | strafe left / right |
| Playing | **left + right mouse** | run forward |
| Playing | **Space** | jump |
| Playing | **F** (from level 5) | your class's movement spell: Blink, Charge… goes where you face |
| Playing | **C** | swing the camera back behind the hero and reset its tilt |
| Any | **G** | toggle the picture polish (`?grade=0` starts it off) |
| Playing | **mouse wheel** | zoom, from over the shoulder out to 70 yd |
| Playing | **right-drag** | turn the hero and tilt the camera |
| Playing | **Esc** | pause |
| Playing | — | abilities cast themselves (no aim) |
| Level up | **1 / 2 / 3** (or click a card) | pick an upgrade |
| Paused | **Esc** | resume |
| Game over | **Enter** (or **Play again**) | back to the menu |
| Any | minimap **+ / −** / minimize | minimap zoom / collapse |

The camera trails the hero's heading at a 61° tilt. Turning with A or D, or right-dragging, swings
the camera and the hero together. **C** recentres the camera behind him. In the menu it slowly
orbits the preview hero. Your race, gender, class and zone are remembered across reloads.

## Gamepad

| When | Input | Action |
|---|---|---|
| Playing | **left stick / D-pad** | move; the hero turns to face where he runs |
| Playing | **right stick** | swing and tilt the camera; movement follows the camera |
| Menu / level up / paused / game over | **D-pad / left stick** | jump to the next button that way (held: repeat) |
| Menu / level up / paused / game over | **right stick** | move the cursor freely |
| Menu / level up / paused / game over | **A / east** | click the highlighted button or card |
| Playing | **B / south** | jump |
| Playing | **A / east** | class movement spell (from level 5): Blink goes where you face, Charge takes the enemy ahead |
| Playing | **X / north** | swing the camera back behind the hero and reset its tilt |
| Playing | **L / R** | zoom out / in |
| Menu | **+ / Start** | Enter World |
| Playing / paused | **+ / Start** | pause / resume |
| Paused / game over | **− / Select** | quit the game |

The camera is the same with a pad as with the mouse: it trails the hero's heading at a 61° tilt,
and the zoom is by wheel or **L / R**. While the right stick steers, the view eases a few yards
ahead of where the hero runs.

On a continent run, a gold 3D arrow floats above the hero and points at the next zone along the
ground, with the distance to that zone and the number of stops reached under the banner. The
horde keeps pace with a hero running the road, and a heal gem lands on the road ahead, toward the
arrow, every 8 seconds (up to three waiting), so healing does not wait on kills.

The run pauses itself when the pad drops out or the machine sleeps, and the pad rumbles when the
hero is hit (where the controller supports it).

On a handheld, `SURVIVORS_MAX_FPS` caps the frame rate and `SURVIVORS_UI_SCALE` scales the HUD and
the cards; the Switch launcher sets both.
